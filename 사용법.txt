DalvitLens 0.7 — 게임 화면 번역 / OBS 출력

실행: DalvitLens.exe 더블 클릭 → '게임으로 돌아가기' → 게임 선택

세 로컬 모델을 선택해서 사용
- 번역 엔진에서 'Hy-MT2 1.8B', 'TranslateGemma 4B', 또는 'EXAONE 3.5 7.8B'를 선택하고 '설정 저장'.
- 'GPU 준비 완료'가 뜨면 F8/F9를 사용합니다. 준비 중에는 잠시 기다렸다 다시 누릅니다.
- 전환 시 이전 모델을 종료하고 새 모델만 GPU에 올립니다. 여러 모델을 동시에 유지하지 않습니다.
- 번역 캐시는 모델별로 분리됩니다. 같은 화면을 번역해도 다른 모델의 결과를 가져오지 않습니다.
- OBS 오버레이와 F8 영역 설정은 모든 모델에서 공통으로 사용합니다.
- Hy-MT2 1.8B: 빠른 번역, 전용 VRAM 약 1.5GiB (측정 환경 기준).
- TranslateGemma 4B: 전용 VRAM 약 2.8GiB (측정 환경 기준).
- EXAONE 3.5 7.8B: 한국어 특화 고품질 번역 (기본값), 파일: models/EXAONE-3.5-7.8B-Q4_K_M.gguf.
- 용어집(glossary.json) 및 OCR 아이콘/파편 정제(Glossary.ps1)가 모든 엔진에 공통 적용됩니다.
- 전환 연결 검사 기록: model-switch-checks.json.

Hy-MT2 1.8B 로컬 번역 (설치됨)
- 번역 엔진에서 'Hy-MT2 1.8B · 빠른 로컬 번역 / GPU'를 선택합니다. 현재 기본값입니다.
- DalvitLens를 켜면 GPU 번역 서버와 OCR 작업 프로세스를 자동으로 준비합니다.
- 'GPU 준비 완료' 뒤 F8/F9로 사용합니다. Ollama 설치나 수동 실행은 필요 없습니다.
- 모델은 한 번 로딩한 뒤 앱을 사용하는 동안 유지합니다. 트레이로 숨겨도 유지합니다.
- 완전 종료하면 관리 중인 번역/OCR 프로세스도 종료합니다.
- 번역문은 내 PC에서 처리하며, 이 모드에서는 Google로 보내지 않습니다.
- F8/F9 처리 완료 상태에 처리 시간(ms)과 저장된 번역 재사용 개수를 표시합니다.
- 연결에 문제가 있으면 설정의 'Hy-MT2 엔진 다시 시작'을 누릅니다.
- 모델 파일: models/Hy-MT2-1.8B-Q4_K_M.gguf (약 1.13GB), 공식 Apache-2.0 배포본.
- GPU 실행기: runtime/llama/llama-server.exe. 파일 검증 정보: local-model-manifest.json.
- 모델 라이선스: models/LICENSE-HyMT2.txt.
- 연결용 local-model.key는 앱이 자동으로 만든 로컬 통신 키입니다. 직접 입력할 필요 없습니다.
- 속도 측정 원본: benchmark-hymt-results.json(번역 엔진), benchmark-pipeline-results.json(OCR 포함).
- 위 측정은 합성 게임 툴팁 이미지 기준이며 실제 게임 부하/캡처/표시 시간은 별도입니다.

F8 영역을 화면에서 직접 지정
- 설정의 'F8 캡처 영역 > 화면에서 영역 지정' 또는 게임에서 Ctrl+Alt+F8.
- 원하는 영역을 마우스로 드래그합니다. 모서리/변을 끌어 크기를 조절하고 안쪽을 끌어 이동합니다.
- '영역 저장' 버튼 또는 Enter로 저장합니다. Esc/우클릭/F10으로 취소하면 이전 설정을 유지합니다.
- 기본 동작은 선택한 크기가 마우스 중심을 따라갑니다. 원래 선택한 위치까지 고정하려면
  '선택한 위치에 고정'을 켭니다. 고정 모드는 영역을 지정한 모니터에서 F8을 사용하세요.
- 고정 위치는 모니터 기준 비율로 저장해 해상도가 바뀌어도 비례해서 적용합니다.
- '기본 영역으로'는 900×650 마우스 따라가기로 되돌립니다. 저장한 영역은 재실행 후에도 유지됩니다.

디자인: Material 3 스타일의 다크 카드 UI, 창 배율 대응 자동 레이아웃.
파지직 시그니처 컬러: 보라 #B373FF / 하늘 #5ABFFF / 패널 #161426 / 숫자 #FFE600.
OBS 번역 패널 바탕은 48% 불투명도로 출력하고 글씨와 테두리는 선명하게 유지합니다.
원문 하늘색 가이드의 불투명도는 25%, 두께는 1px입니다.
번역 카드 테두리도 1px이며 부드러운 드롭 섀도를 사용합니다.
PC 오버레이는 픽셀별 알파 투명도로 표시해 가이드가 게임 화면을 덜 가립니다.
설정/OBS/번역 기록은 휠과 보라색 슬림 스크롤바로 이동합니다.
번역 기록의 전체 텍스트는 '번역 기록 복사'로 복사합니다.
assets/DalvitLens.png는 흰 외곽을 제거한 투명 PNG, assets/DalvitLens.ico는 Windows 아이콘입니다.

OBS 송출 연동
DalvitLens 실행 중 http://127.0.0.1:18765/ 를 OBS 브라우저 소스에 넣습니다.
너비 1920, 높이 1080, 소스 위치 0,0, 배율 1.0으로 설정합니다.
게임 캡처 바로 위, 캠과 알림 아래에 배치하면 됩니다.
게임이 3840x2160 전체 화면이고 OBS에서 0.5배로 표시될 때 위치가 일치합니다.
모니터 좌표를 전체적으로 1920x1080으로 변환하므로, 게임 캡처를 자르거나
이동/확대하거나 다른 비율로 배치하면 OBS 소스도 동일하게 변환해야 합니다.
PC 오버레이와 같은 문단/번호/페이지가 표시됩니다. 단축키 안내는 송출하지 않습니다.
F10 숨김, 마우스 이동에 따른 숨김, 창 전환 시 OBS도 약 0.25초 뒤 숨겨집니다.
DalvitLens 종료/연결 실패 시 OBS는 마지막 번역을 계속 남기지 않고 숨깁니다.
인터넷 서버가 아니라 이 PC의 루프백 주소만 사용합니다.
설정이나 API 키는 이 주소로 제공하지 않습니다.
4K를 절반으로 줄이면 글씨도 작아집니다. 방송에서 작다면 설정의 글자 크기를 올려주세요.
디스플레이 캡처로 PC 번역창까지 이미 찍고 있다면 브라우저 소스를 더하면 중복됩니다.
게임 캡처와 별도 브라우저 소스를 조합하는 구성을 권장합니다.

OBS 자동 소스 추가(OBS WebSocket 서버가 켜져 있어야 함)
PowerShell에서 .\Connect-OBS.ps1 실행. 기본 대상은 '게임화면' 장면입니다.
게임 화면/송출을 시작하거나 장면을 전환하지 않고 번역 소스만 추가합니다.

F7  빈 공간에 모두 표시하지 못한 번역의 다음 묶음 보기
F8  지정한 크기의 마우스 주변 또는 지정 위치를 캡처해서 번역
F9  마우스가 있는 모니터에서 현재 활성 창 영역을 번역
F10 번역 숨김 / 진행 중 작업 취소

번역창은 클릭을 게임에 통과시키며 포커스를 가져오지 않습니다.
같은 번호의 원문 테두리와 한글 상자를 대응해서 읽습니다. 연결선은 표시하지 않습니다.
인식한 모든 원문 영역과 번역 상자를 피해서 빈 공간에 배치하고 상자 간격을 유지합니다.
빈 공간이 부족하면 F7로 다음 묶음을 봅니다. 한 문단조차 들어갈 공간이 없거나
문단이 화면 높이보다 길면 트레이의 번역 기록에서 전체 내용을 확인하세요.
OCR로 인식되지 않은 이미지·아이콘·게임 UI까지 피하는 것은 아닙니다.
트레이 아이콘을 더블 클릭하면 설정과 마지막 번역 기록을 봅니다.
창의 X 버튼은 트레이로 숨김입니다. 완전 종료는 트레이 우클릭 > 종료.
프로그램 폴더 전체를 유지하세요. Worker.ps1이 필요합니다.

권장: Windows 10/11, 테두리 없는 창모드, 영어 OCR 언어 기능.
다른 앱이 F8/F9/F10을 쓰면 먼저 그 앱에서 단축키를 해제하세요.
게임 조작 중 단축키가 가로채는 문제를 피하려면 게임 키 배정도 확인하세요.
영어 OCR이 없다는 안내가 나오면 Windows 언어 설정에서 영어의 기본 입력 기능을 설치하세요.

번역 엔진
- 기본: EXAONE 3.5 7.8B · 고품질 로컬 번역 / GPU (내 PC에서 처리).
- 로컬 대안: Hy-MT2 1.8B (초고속) / TranslateGemma 4B (중간 체급).
- Google 간편 연결: API 키 없이 동작하는 비공식 연결입니다.
  서비스 사정에 따라 차단되거나 실패할 수 있습니다. 보장된 공식 무료 API가 아닙니다.
- Google Cloud: Translation Basic API를 켠 프로젝트의 API 키가 필요하며 사용 요금이 발생할 수 있습니다.
- 용어집 설정: glossary.json 파일에서 고정 UI 번역(exact), RPG 용어 힌트(terms), 후처리 치환(postReplace)을 직접 추가·수정할 수 있습니다.

데이터
Google 모드는 OCR로 읽은 영문만 Google에 전송합니다. 이미지 자체는 전송하지 않습니다.
캡처 이미지는 임시 폴더에 저장하고 처리 완료/취소 시 삭제합니다.
강제 종료/PC 종료 시 임시 폴더에 남을 수 있습니다.
번역문은 translation-cache.json에 저장합니다. 재사용 시 응답이 빨라집니다.
API 키는 settings.json에 현재 Windows 사용자용 DPAPI 암호문으로 저장됩니다.

첫 버전의 범위
- 자동 실시간 번역이 아니라 누를 때마다 찍는 번역입니다. 게임을 일시정지하지 않습니다.
- F8은 마우스가 캡처 시점에서 160px 넘게 이동하면 숨깁니다.
- 다른 창으로 전환하거나 45초가 지나도 숨깁니다.
- 같은 위치에서 툴팁 내용만 바뀌는 것은 아직 감지하지 않습니다. F10 후 다시 번역하세요.
- F8은 주변의 다른 UI도 함께 읽을 수 있습니다. 툴팁 경계 자동 탐지는 다음 개선 대상입니다.
- 전체 화면 인식에서는 문단/열 분리와 배치가 휴리스틱입니다. 복잡한 UI에서는 오인식할 수 있습니다.
- 공간이 부족해 표시하지 못한 번역은 설정 창의 마지막 번역 기록에 남습니다.
- 4K 화면은 OCR 크기 제한에 맞춰 축소합니다. 아주 작은 글씨 인식률은 떨어질 수 있습니다.
- 독점 전체화면, HDR, 보호된 게임 화면에서는 캡처/표시를 실제 게임에서 확인해야 합니다.
- OBS 게임 캡처에 오버레이가 함께 나오는지는 캡처 방식에 따라 확인이 필요합니다.
- 용어 사전, 자동 툴팁 변경 감지, 단축키 변경 UI는 아직 없습니다.
